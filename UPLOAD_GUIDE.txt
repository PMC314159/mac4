R2 ZIP 4~6개 버전

GitHub 저장소 루트에 아래 파일을 덮어씁니다.
- index.html
- package.json
- vercel.json
- api/render.js
- api/upload.js

Vercel 프로젝트 환경변수
- R2_ACCOUNT_ID
- R2_ACCESS_KEY_ID
- R2_SECRET_ACCESS_KEY
- R2_BUCKET_NAME=pair-archive-render

Cloudflare R2 버킷 CORS
- 실제 Vercel 사이트 주소 허용
- Method: PUT
- Header: Content-Type
- Expose: ETag

동작 방식
- HTML + 모든 원본 이미지를 브라우저에서 ZIP 1개로 묶음
- R2에 임시 ZIP 1개 업로드
- Vercel Chromium이 ZIP을 풀고 전체 페어틀을 PNG로 렌더링
- 렌더 성공·실패 후 임시 ZIP 삭제

파일 교체 후 GitHub Commit -> Vercel 새 배포를 확인합니다.
